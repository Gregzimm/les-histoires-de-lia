À propos

Les Histoires de LIA est un service de contenu automatisé qui utilise l'intelligence artificielle pour créer et publier des histoires audio destinées aux enfants. Notre pipeline génère quotidiennement un épisode complet : narration, illustrations et sous-titres.

Le contenu est publié via l'API TikTok Content Posting directement sur notre compte @histoires_de_lia. Toutes les histoires sont vérifiées pour s'assurer qu'elles respectent les standards de sécurité pour les jeunes publics.

Ce service utilise l'API TikTok pour la publication automatisée de contenus vidéo sur la plateforme TikTok, conformément aux Conditions d'utilisation pour les développeurs de TikTok.
